## 内容

- 8 类自制 GLB、9 个场景实例：6 台主体设备、2 台泵、1 个带管廊/阀门/排水沟/控制柜的化工车间背景。
- 14 条原生流体路径，与背景中的物理管道路径一致；颜色区分物料、蒸气、冷凝、冷却及母液回流。
- 3 个搅拌模型内嵌 4 秒一圈的 glTF 动画（15 rpm 演示），局部剖视显示桨叶。不是整机自转。
- 原生 2D 工艺按钮和 3D 设备点击通过 `set-text` 更新固定信息卡，并保留全景镜头；可以手动拖动旋转、滚轮缩放。
- 模拟数值是标明来源的展示样例，没有绑定真实 IoT 点位，也不下发控制指令，不是工艺仿真或联锁验证。

## 重现与维护

`node scripts/generate-silver-workshop.mjs` 生成米制、Y-up、带内容哈希的模型，并用 GLTFLoader 重新载入检查。`models/manifest.json` 记录校验摘要、动画数、包围盒与所有管线路径。`author.ts` 是原生文档的可复现组成方法。

临时导入页面仅调用现有鉴权 API 创建项目、上传模型、按 revision 保存场景和画布，交付后移除。更新应显式针对本文件项目 ID，不能覆盖其他项目；私有现场资料和生成资产不自动提交 Git。
