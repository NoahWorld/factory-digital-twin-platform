# 生产车间模型与组装预设（地坪 v3 / 设备 v2）

这套原创程序化模型参考了用户提供的 EasyV 演示中的生产车间类型与布局需求，没有提取或复制其模型、贴图或业务数据。目标是让设备与空间容易辨认，并能在平台继续搭建。

## 材质与穿模改进

v2 降低漆面饱和度，使用确定性生成的 256 × 256 PNG 颜色、粗糙度/金属度和法线贴图。金属呈现拉丝变化，纸箱有纤维纹理，地坪有颗粒；贴图全部内嵌 GLB。倒角、紧固件、接缝、线缆和控制面板补足设备结构。共享运行层在摄影棚模式增加单张 2048 × 2048 PCF 主光投影，增强落地感，并负责释放阴影资源。

原机械臂朝向机器，回转动画的伸展空间进入机壳。新版调整朝向与位置，为机器、机械臂、台面和输送线留出独立空间。生成器按 60 Hz 采样完整周期，对动态模型与静态设施逐网格检查包围盒：4 个机械臂各 481 次采样，2 辆 AGV 各 961 次采样；机械臂与机器的水平包围盒最小间隙约 0.455 米，所有动态实例的扫掠包围盒互不重叠。

检查排除支撑地坪，允许 1 毫米接触误差。这是保守的离线布局检查，不覆盖模型内部自碰撞、用户后续改动或采样点之间的连续碰撞，不是 Rapier 动力学或工程安全认证。

## 地坪深度冲突修复

旧地坪把区域色块、接缝和交通线叠成薄盒子，部分表面仅相差 0.5 毫米；原相机 near=0.01、far 至少为场景半径的 100 倍，远处斜视时深度精度不足，产生蓝灰色块互相覆盖的 Z-fighting。v3 地坪将 28 × 20 米顶面按色块和标线边界切分，所有顶面位于 Y=0，每个位置只有一个表面，保留侧面与底面。颜色通过材质分组表达，不再依赖叠层厚度。

轨道相机的 near/far 按场景包围球与中心沿镜头视轴的有符号深度动态拟合，随旋转、缩放和平移更新；行走相机仍使用独立配置。地坪测试验证顶面总面积 560 平方米，并对 300 个非边界采样点验证每条向下射线只有一个交点；相机测试覆盖场景内外、远距离和小场景的裁剪与深度精度。

## 使用

1. 在平台创建「3D 场景」项目。
2. 在全新空场景点击「搭建示例车间」。预设先进入编辑草稿，资源缺失或超过预算会明确报错。
3. 初版既有示例可点击「替换为新版示例车间」替换草稿，然后点击「保存场景」。预览从项目 API 读取保存版本，模型可分别选中、修改名称、移动、旋转、缩放和隐藏。
4. 已有布局可点击「更新内置模型」，仅升级有新版本的资源引用，保留位置、缩放、名称、业务绑定和场景设置，再点击「保存场景」。
5. 也可以从模型积木或资源库单独复用任一模型。静态内置模型无需 R2；客户模型上传沿用现有权限与存储。

实际交付验证使用本地项目「示例生产车间 · 机械臂与 AGV」，项目 ID `ae0ea21c-222c-4903-be37-8ab82064f4ee`。新版模型及布局保存为修订版 2，随后调整初始镜头比例并保存为修订版 3；地坪 v3 单独升级并保存为修订版 4，98 个实例的布局保持不变。这个 ID 属于本地验证数据，其他环境按上述步骤创建新项目。

## 尺寸、动画与边界

- 单位为米，Y 轴向上。地面模型以顶面 Y=0 定位，落地设备以脚底附近为原点；壁挂摄像头以安装板为锚点。平台实例旋转单位为度，GLB 动画使用标准四元数/位移轨道。
- AGV 沿模型本地 +Z 方向移动 5.5 米再返回；移动整个实例会平移路线，旋转实例会旋转路线。路线属于模型内嵌动画，不是平台上的路线编辑器。
- 机械臂只有基座回转演示，未模拟取放工件、逆运动学或加工工艺。三色灯是静态模型，摄像头没有接入视频，门没有开关动画。
- 全部实例初始 `assetId=null`，没有实时生产指标；后续可显式关联 2D 项目再绑定业务资产。没有添加物理碰撞体或宣称已接入 Rapier 行走。

## 源文件与再生成

源脚本是 [`scripts/generate-workshop-models.mjs`](../../scripts/generate-workshop-models.mjs)，依赖平台已有 Three.js、GLTFExporter 及 Node.js 内置库。贴图生成见 `scripts/workshop-surface-textures.mjs`，空间检查见 `scripts/workshop-motion-check.mjs`，地坪拓扑见 `scripts/workshop-floor.mjs`。无需 Blender、外部贴图或模型下载。SVG 缩略图直接投影对应模型几何生成。

```sh
node scripts/generate-workshop-models.mjs
pnpm test:workshop-motion
pnpm test:models
pnpm test:standalone-3d
pnpm test:scene-runtime
pnpm --filter @factory-twin/web check
pnpm --filter @factory-twin/web build
```

生成物：`apps/web/public/models/workshop/` 中的 GLB/SVG、`shared/workshop-models.ts` 中的资源白名单、`shared/workshop-layout.ts` 中的正式场景实例和设置，以及 [`workshop-kit-report.json`](../workshop-kit-report.json) 中的哈希/体积报告。内容变化必须升级相应模型 ID 并保留旧版本资源，不能让已经保存的项目在原 ID 下悄悄换模型。

测试覆盖 GLB 哈希、唯一节点名、PBR 内嵌图片、动画有限值与循环接缝、动画中途穿模反例，以及 98 个实例的 API 契约、引用完整性和资源预算。浏览器验证覆盖原项目替换草稿、保存、总览和设备近景。初版资源目录 `shared/workshop-models-v1.ts`、旧地坪目录 `shared/workshop-models-legacy.ts` 和对应文件继续保留，不让旧项目在同一 ID 下悄悄换模型。
