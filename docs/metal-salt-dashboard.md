# 金属盐产线展示看板

当前分支：`iot-3d`。入口：项目页「展示看板」中的「xxx金属盐看板」、三维编辑器顶部「产线看板」，或 `#/projects/{项目ID}/metal-salt-dashboard`。

项目页案例由 `apps/web/src/dashboard/dashboard-cases.ts` 显式绑定源项目 ID，仅当 IoT 项目列表返回对应 3D 项目时显示。案例入口跨 2D/3D 分类可见，不创建重复项目、不计入项目数量；项目删除或当前账号不可见时，入口一并隐藏。其他环境需显式配置当地源项目，不能按名称猜测。

面向甲方和参观人员，以保存的三维车间为主体，左右展示七台设备的模拟参数；默认标题为“xxx金属盐看板”。沿用深蓝底、蓝青强调色、白色主文与绿色运行状态。大屏按 16:9 设计，窄屏改为场景在上、数据在下，详情为可关闭浮层。

## 数据与隔离

- 路由仍在 IoT 会话验证后进入，场景通过现有 `standaloneScenePath` 与 `request` 读取，模型继续经 IoT 鉴权和 MinIO 获取。没有新增后端或匿名入口。
- 只读已保存场景，不复制场景到新画布、不 PATCH 原场景，不改变原有相机设置。展示镜头调整仅在当前看板内有效。
- `apps/web/src/dashboard/metal-salt-demo.ts` 是独立演示配置。标题、工序说明、指标、单位、小数位、基准和波动范围集中维护。模拟数据不写入 IoT，不作为真实数据请求失败时的替代值。
- 七个设备名称必须唯一对应可见场景实例（忽略空白），绑定完成后使用实例 ID 选择高亮。缺失、隐藏或重名明确报错，不按数组位置猜测。此名称映射仅用于演示配置，正式现场数据需配置 IoT 稳定设备 ID。
- 参数每两秒更新一次，页面隐藏或用户暂停时停止推进模拟；趋势展示最近 60 秒模拟时间。全局“模拟数据”和页脚说明始终保留。
- 点击模型、侧栏、底部工艺路径都可打开同一设备详情；键盘可操作侧栏和工艺路径，Escape 关闭详情并返回设备按钮。
- 俯视布局、产线正视复位、全屏展示和暂停模拟均为浏览器本地操作。

## 视觉与实现边界

- 页面实现位于 `apps/web/src/dashboard/MetalSaltDashboard.tsx`，样式位于同目录 `metal-salt-dashboard.css`。复用现有 `Model3DNode` 与 `standaloneRendererNode`，未新增独立三维运行引擎。
- 对照 `apps/web/src/theme/theme-palette.css` 与 `apps/web/src/styles.css`，延续深海军蓝表面、蓝青强调、浅色文字、绿色状态及中文无衬线字体。看板颜色与布局限定于本页面，不更改全局主题变量。
- 桌面采用全视口三维背景、左侧三台设备和批次质量、右侧四台设备、顶部订单进度、底部环境与公用工程及固定工艺路径。宽度不超过 1100px 时改为场景上置与可滚动数据区，详情固定在视口内并允许自身滚动；宽度不超过 600px 时设备卡片改为单列，卡内指标保留两列。桌面高度不超过 850px 时收紧纵向间距。
- 本次为现有视觉体系的普通扩展，执行路径为 code-led，没有批准的图片 comp。页面策略记录在 `.impeccable/surfaces/metal-salt-dashboard.md`；现有全局 `DESIGN.md` / `.impeccable/design.json` 未发现，本次不补建或改写全局设计系统。

- 展示环境加入公用管廊、阀门、围堰、格栅排水沟、检修平台、仪表柜与洗眼设施。`scripts/generate-chemical-workshop.mjs` 可复现生成 613 KB 的内置 GLB；属于概念示意，不是工程设计图。
- `chemicalWorkshopScene` 仅在看板内替换 `builtin:workshop-*` 配景；七设备与连接管道仍使用 IoT 已保存实例，原项目编辑场景与 MinIO 资源未修改。环境作为显式登记的内置公共模型随前端交付。

- 新增订单、批次、产出计划与完成率、班次、抽检与纯度、回收率、车间温湿度、冷却水、排风、用电、用水、压缩空气。每台设备显示四项工艺指标、编号、启停和联锁；详情补充订单关联、机旁湿度、驱动转速、运行小时和保养日期。
