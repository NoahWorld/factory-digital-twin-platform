## M1 实施决定

沿用资产台账、资产指标映射和 REST 标准化接口；公共组件只读标准 `metricKey`，不接触上游字段路径。新增项目级组件绑定表，节点仍只存 `dataBindingRefs`，绑定定义与画布在同一版本事务内保存。无引用的旧组件继续使用原有静态 props，运行值只在内存派生，不写回编辑配置。

绑定明确目标（指标值、对比序列、表格行）、固定/当前选择的稳定资产 ID、指标键和类型。右侧属性区配置绑定；项目工具栏增加独立于 3D 的资产与指标入口。预览共享同一需求集、缓存和资产选择，表格或设备选择器均能在纯二维页面切换资产。服务端验证项目归属、引用、目标和类型；缺值/类型错误/陈旧/失联明确显示并恢复。
