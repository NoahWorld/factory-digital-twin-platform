# M7 代表规模、性能与专业能力

M6b已提交ac0ce5b。M7以roadmap原定预算为准，不将已有轻量24/240/2400面约60FPS视为大模型验收，也不移除GIS等已纳入能力。

第一项建立可重复基线：1/10/100实例分别达到约10万与100万实际提交三角面，使用有真实顶点/索引/法线的合成曲面GLB，记录原始文件、材质、纹理、生成参数、资源SHA、模型报告与实际提交量。全部可见实例布置在视锥内，不重复同一索引伪造几何量，也不靠隐藏内容过关。固定Node发布运行版本，冷加载与缓存状态分开。

运行页面新增只读场景性能面板，读取同一渲染器的帧数、提交三角面、调用数和资源副本计数；最近240帧的间隔与CPU提交耗时分开。暂停/加载/错误不作为当前帧率，切换配置清掉旧采样。资源个数不是显存大小，CPU提交耗时不是GPU总耗时。

初始预算沿用p95帧间隔≤33.43ms（约30FPS）、主要编辑操作p95≤100ms。加载时间独立报告，不用放宽阈值抹去失败。根据相同规模的结果选择并完成有产品入口的压缩、LOD/实例化、加载和释放优化，保留原资源、稳定引用、拾取/资产状态、版本修复及回滚；LOD降低的实际提交量须单独标明。

后续分层验证10/100资产、2/5独立客户端以及至少30分钟持续运行，包含源故障恢复、页面/动画/历史告警操作，记录多点内存/队列/连接/资源趋势与退出后的归还。GIS作为独立能力交付，需明确坐标/离线资源与保存/运行/交互契约。公司真实模型和目标硬件仍单列待验证。

## 首轮基线（2026-09-13）

本机Apple M5/16GiB、Chrome152/ANGLE Metal、1440×1000视口，实际三维渲染缓冲1838×998。固定Node发布版本，6组规模×新浏览器上下文/缓存重载各观察4秒，最近240帧同时记录提交三角面的最小/最大值；每组均等于完整规模。原始GLB为1材质、0外部纹理的生成曲面，浏览器上下文冷缓存不等于磁盘/GPU驱动完全冷启动。

最终m7-baseline-final.log中p95帧间隔16.8–18.6ms，均达到当前33.43ms预算。单文件最大24095688字节；每个视窗只取得一份模型文件和报告、共享一份几何/材质副本。缓存重载模型内容transferSize为0，报告仍按权限读取。冷首帧受首次WebGL/驱动编译影响，不能据单轮顺序比较宣称百万面比十万面更快。

相同执行还通过资源共享/释放、旧模型性能、实例更新失败、WebGL及模块加载重试共10项。该结果只是静态无纹理曲面的短时基线，长时、多客户端、实时资产、压缩/LOD/实例批处理和GIS仍须后续验证。下一项优先补可复现压缩版本与解码能力；Meshopt不会降低面数或draw calls，不承诺提高此场景的FPS。

## Meshopt读取与能力边界

已接Node模型检查、headless旧名称解析、浏览器资源池与项目包实际资源复验的同一Meshopt解码链。浏览器使用Three0.185.1内带的Meshopt1.1解码器，Node显式使用meshoptimizer1.1.1，均随程序离线分发。实际压缩模型的检查报告新增可选compression，冻结快照声明meshopt-model-v1；无压缩模型不补字段，不改旧包身份。

解码之前检查EXT的模式/stride/filter/count、父视图布局、fallback声明、总声明缓冲128MiB、实际压缩字节范围及累计解码64MiB。不能只限制accessor，因为小accessor可引用声明巨大解码目标的压缩view。API和浏览器都检查真实BIN或base64内嵌数据，错误布局不会进入decoder。

本地workerd探针未能完成内嵌WASM解码器的顶层ready初始化（runtime reported hung），因此当前Worker实现不注册此能力，并在接收这类模型时明确503且不保存对象；旧模型仍按原路径处理。Node与Chrome已有实际成功证据，不将本地探针结果泛化为所有Cloudflare WASM配置均不可用。

压缩生成最终采用官方Meshopt编码器直接处理bufferView，保留原始glTF节点、accessor、动画、材质与图片JSON，不经过Transform重导出。索引使用INDICES以保留原顺序，U8索引视图原样保留；属性不量化、不重排、不减面。多内嵌buffer组合为自包含GLB，无法安全识别的扩展明确拒绝。原资源和全部版本谱系保留，压缩不保证文件变小或帧率增加。

## 生成压缩版本 checkpoint（2026-09-19）

3D编辑器“模型版本与替换”可生成Meshopt压缩版本、预览并应用，继续使用原项目编辑操作/撤销重做/保存和发布流程。生成后保留原始节点与clip定位并通过服务器内部可信派生关系继承ID；普通上传不能请求任意身份继承。来源SHA、算法版本、输入大小、压缩/保留视图数及精确属性/索引验证记录在GLB的asset.extras.newpowerCompression，检查报告读回；包导入核对原祖先SHA和每个缓冲视图的实际解码字节，不能靠声明伪造统计。

生成在独立进程中进行，单宿主1个任务、30秒、Node堆256MiB；输出25MiB限制在append累加与完整包装前执行，避免重叠view先分配巨大外部Buffer后报错。取消等进程退出才释放任务槽。写入前及最终SQL重新检查权限；已提交记录的后续读回失败不删除其模型文件。

本轮Owner要求保持总目标暂停，仅推进至此checkpoint并推送newpower；不继续LOD/GIS/长时稳定或M8。后续任务保留，不将M7或总目标标记完成。
