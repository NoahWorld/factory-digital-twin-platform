# M4 交互与动画实施

起点 `7b2f1e3`，M3 本地验收通过。此阶段继续完整目标，先交付点击/数据事件→条件→状态与二维三维选择的可配置执行链，再接模型动画、镜头和路径；不为每个示例另写业务逻辑。

项目 schema 增加版本化 interactions（状态定义与规则），与页面/场景共用根 CAS、草稿和撤销。无 DOM 的共享执行器通过宿主接口调用实际运行能力；编辑配置不被运行值覆盖。初始事件覆盖页面进入、组件点击/值改变、资产选择、指标变化、连接状态和状态变量变化，自定义事件用于复用。表达式只读常量、事件字段、状态和标准指标，不执行脚本。

状态有项目/页面作用域；离页取消页面执行、定时器和后续动作，项目状态在翻页时保留。退出预览、换项目全部释放。每条事件链共享预算，衍生事件不重置计数；同值状态不触发变化。规则重入明确支持取消旧运行或忽略新触发，运行日志区分成功、跳过、失败、取消和循环终止。数据只在真实值/连接状态变化时触发；陈旧与失联不被当成有效指标值。

复制页面或组件时返回稳定 ID 映射，复制相应页面规则并只重映射实际引用字段；共享场景保持共享。删除目标须同时修复引用或明确报错。引入场景对象动作和动画时，必须扩展 M3 的模型替换引用清单，不能让动作目标逃过预检。动画由统一视窗帧循环执行，取消和完成状态均有明确语义。

首项验收：从界面建立按钮事件、条件、顺序动作，保存重开→选择设备并影响已有三维高亮→设置状态/显示目标→调试读回；复制页面后操作副本，切页取消延迟动作；循环和失联输入有明确结果。接口验证归属、未知字段、悬挂引用、权限与 CAS。后续动画专项继续沿同一契约扩展。

## 首项实际契约

项目 schema v4 的 `interactions: {states, rules}` 已进入共享解析、`interactions.set` 操作、草稿及根 PATCH。v3 和此前版本迁为空交互，旧画布接口继续保留项目中的交互配置。状态最多100个、规则200条、每条32个顺序动作；条件最多8层/64项，取值只允许有限数字、布尔、空值和有界文本。类型错误、跨页状态、悬挂节点/页面、跨项目设备或未配置指标会被拒绝。

事件包括 page.enter、node.click、node.change、asset.select、data.change、connection.change、state.change 和 custom；首项动作是 state.set、asset.select、page.navigate、node.visible、delay、event.emit。三维对象点击沿用已验证的对象/资产选择入口发事件，二维动作可通过同一资产选择带动三维高亮。此时尚未提供指定对象动作、模型动画和镜头轨道，后续继续实现。

执行器每个预览项目会话一份，翻页保留项目状态，退出预览销毁。离页取消页面运行并递增代次；返回同一页面也不复活旧排队事件。每链最多128步（事件、规则、动作共用预算），同时最多32条链和64条规则，记录最近256条调试项。重入为取消全部旧存活运行或忽略新触发；等待与宿主调用可取消，宿主单次最多60秒，失败停止后续动作。设置相同状态/设备不产生重复变化事件。

数据需求合入现有去重采集；没有组件绑定的数据条件也会采集所需资产，通配数据事件覆盖当前项目资产。只发布值或连接状态的实际变化；失联/陈旧/缺失取值为 unknown，NOT 不会把未知数值比较变为 true。运行显隐、状态与选择不写回服务器。页面跳转先同步挂载新页，再沿原事件链发进入事件，因此真实页面互跳也受同一预算约束。

复制节点或页面时重映射明确节点/状态/页面引用，常量文本不随 ID 修改；共享项目状态按设计共用，复制页面状态则获得新 ID。页面删除移除该页拥有的规则和状态，跨范围残留引用仍会阻断操作，直到明确修复。
