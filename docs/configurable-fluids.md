# 可配置流体组件

独立 3D 项目提供公共流体组件。用户在任意场景中设置路径和参数，由共享运行层生成三维曲面与粒子；无需修改模型文件或编写某个项目的专用生成脚本。

## 操作

1. 打开 3D 项目编辑器，在「图层 → 流体」添加气体、液体或熔融体。
2. 选择 XZ、XY 或 YZ 绘制平面和固定轴坐标。左键单击场景添加点，拖动旋转视角，滚轮缩放。切换平面仅影响下次取点，可组合成三维路径。
3. 至少选择两个不同的点；点击路径列表可用鼠标重新定位该点，或修改 XYZ。支持撤销末点、删除指定点和清空路径。
4. 配置颜色、连续流／扩散流、半径、扩散幅度、视觉流速、透明度、正反方向、播放与显隐。三种类型均支持两种形态；扩散从实际流向的起点逐渐变宽，反向时一起反转。
5. 点击「应用流体」，再「保存场景」。保存后重新打开、独立预览、2D 中嵌入该场景和项目封面都使用相同配置。

未应用路径属于临时编辑会话，可取消还原；不完整路径不进入正式场景文档。未应用时阻止保存和进入预览。套用模型场景模板会保留现有流体，用户需核对它们与新模型的位置关系。

## 契约与存储

`shared/fluids.ts` 是定义、默认草稿和边界的单一来源。`StandaloneSceneDocument.fluids` 为同级数组，旧文档仅在缺失时解释为 `[]`，显式 null 或损坏配置报错。PATCH 通过 `fluids` 整数组替换；与实例和设置共享 `expectedRevision`、权限、事务、审计及封面失效机制。流体配置不复制进 2D Canvas JSON。

每条流体保存：稳定 ID、名称、类型、颜色、形态、三维路径点、半径、速度、扩散幅度、不透明度、方向、可见性和播放状态。位置使用场景本地 Y-up 坐标；速度是每秒场景单位，扩散幅度是相对起始半径的增量倍数。扩散终点范围为 `radius × (1 + spread)`，粒子外观有额外软边。

- 每场景最多 32 条，每条 2～64 点；坐标 ±10000。
- 半径 0.01～20，速度 0.01～30，扩散 0～10，不透明度 0.05～1。
- 拒绝未知字段、重复 ID、相邻重合点和非有限数值；保留字段与数组索引错误上下文。
- Java 使用现有场景 settings JSONB 内部 `fluids` 字段，不增加数据库迁移；GET／manifest 将其拆成公共同级字段，设置 PATCH 会保留它。公共 settings 不接受嵌套 fluids。
- 历史 Worker 运行环境必须应用 `0023_scene_fluids.sql`，增加 `fluids_json`。一次性历史 Wrangler 快照恢复脚本未扩展为新流体的迁移工具。
- Java schema 由共享 TS 生成，修改契约后执行 `pnpm backend:contracts`。

## 运行与边界

`FluidManager` 不创建 renderer、相机或循环；由 `scene-runtime.ts` 统一调用。每条流体以自身首点为几何局部原点，保留场景坐标配置，避免远离原点的短路径发生浮点精度退化。Catmull–Rom 路径按弧长采样；液体／熔融体的连续流使用管面着色与粒子，气体和扩散形态使用相机朝向的实例化粒子。每条最多 256 个粒子，逐帧更新复用已分配缓冲，不重新创建几何。

全局动画开关／速度与每条流体的播放／速度共同生效。隐藏、离屏或页面不可见时停止相应更新。增删、形状修改和卸载释放自有几何及材质；外观修改复用几何。运行诊断包含流体、可见流体、粒子、几何和材质计数。

鼠标射线先转换到场景局部坐标再与绘制平面求交，支持场景居中及旋转；平行、平面位于相机后方或越界会显示可恢复的选择错误。绘制时暂停场景自动旋转并禁用模型变换轴，摄像机仍可拖动。模型和流体共用最近命中选择，模型墙体会遮挡后方流体。辅助线和路径点只出现在编辑态。

当前能力是可配置的三维视觉流动，路径不依赖某个内置模型。不计算压力、温度、粘度或真实流场，不自动避障、附着移动部件或导出新的 GLB；这些能力需要单独定义契约与验收。

## 验证

- `pnpm test:fluids`：共享 TS／Java 正反样例、SQLite 保存恢复／修订冲突／事务回滚、弧长与方向、帧率独立性、扩散、资源释放、拾取遮挡和局部坐标求交。
- `pnpm test:fluids-browser`：公共编辑器表单及路径会话浏览器回归。
- `pnpm test:fluids-scene-browser`：在本机现有 Vite 5173／Java 18080 上创建临时项目，鼠标画路径、保存重载、画布选择、预览及真实封面截图，结束精确删除临时项目；截图保存在输出的系统临时目录。仅为浏览器图标请求提供空响应，场景和 API 使用真实服务。
- `pnpm backend:smoke:fluids`：本地 Java／PostgreSQL 流体持久化、权限、修订冲突与封面失效回归，不占用模拟数据源的 8790 端口，结束精确删除临时项目和账号。
- `node scripts/test-fluid-render-browser.mjs`：六种类型与形态组合的真实 WebGL shader、画面运动、GPU 资源释放，以及自动旋转后绘制／清空／继续绘制的坐标稳定性。
- 浏览器脚本使用已有 Playwright 与 Chrome；通过 `PLAYWRIGHT_MODULE_PATH`、`CHROMIUM_EXECUTABLE` 指定，不下载浏览器。
- `pnpm check`、`pnpm --filter @factory-twin/web build`、`pnpm test:scene-runtime`、`pnpm test:project-covers`、`pnpm test:composable-dashboard`。
- `pnpm backend:contracts:check`、`pnpm backend:verify` 与本地 `pnpm backend:smoke`。Java 在缺少系统 JDK 时显式配置 `JAVA_HOME`。
